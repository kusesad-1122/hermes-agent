# Hermes Agent · 安卓手机使用指南(傻瓜版)

> 这份文档教你把 Hermes(一个会自己学习、能用工具、能记事的 AI 代理)装到
> **安卓手机**上使用。全程按步骤点,不需要懂编程。

---

## 一、先搞懂:它是"两半"

Hermes 不是一个普通 App,它由两部分组成:

| | 名字 | 干什么 | 装在哪 |
|---|---|---|---|
| 🧠 **大脑** | `hermes dashboard`(Python 程序) | 真正的 AI:思考、用工具、读文件、记忆 | 你手机的 **Termux** 里 |
| 🖥️ **脸** | 网页界面(Web 仪表盘) | 你看到的聊天界面 | 手机浏览器 / 主屏幕图标 |

"脸"通过网络(WebSocket)连"大脑"。这就是为什么手机也能用——**换一张手机上的脸,连同一个大脑**即可。

> 💡 **读手机文件**这个功能天生就有:因为"大脑"就跑在你手机里,它读文件时读的就是
> 你手机里的真实文件。配合你的 **root**,还能读普通 App 碰不到的地方。

---

## 二、路线图:你现在处于哪一步?

```
你现在:只有一部 root 手机,电脑还没到
   │
   ├─▶ 第一步(今天就能做)：Termux 装大脑 + 手机浏览器当 App(PWA)
   │        ✅ 不需要电脑   ✅ 能聊天   ✅ 能读手机文件
   │
   └─▶ 第二步(电脑到了以后)：
            方式A：手机 App 连"电脑上的大脑"(更稳,不占手机)
            方式B：把界面打包成正式 .apk 安装包(更像原生 App)
```

先做**第一步**就够用了。第二步随时可以升级。

## 三、第一步:今天就把它跑起来(只需手机 + root)

### 1. 安装 Termux(必须用 F-Droid 版)

- 打开 **F-Droid**(https://f-droid.org),搜索安装:
  - **Termux**(手机上的 Linux 环境,大脑就住在这)
  - **Termux:API**(用于后台保活,强烈建议一起装)
- ⚠️ 不要用 Google Play 里的 Termux —— 那个版本太旧、会出问题。

### 2. 一键安装 Hermes 大脑

打开 Termux,依次粘贴运行:

```bash
# 拿到本仓库(如果你还没有的话)
pkg install -y git
git clone https://github.com/NousResearch/hermes-agent
cd hermes-agent

# 一键安装(会自动装依赖、申请存储权限、装 Hermes)
bash scripts/android/hermes-termux-setup.sh
```

安装时手机会弹一次**存储权限**窗口 —— 请点【允许】(这是能读 `/sdcard` 里
照片、下载、文档的关键)。

> 第一次安装会下载不少东西,慢是正常的,耐心等。

### 3. 配一个模型 / 填 API Key

```bash
hermes setup
```

按提示走一遍。**没有自己的 Key?** 可以用 Nous Portal 一站式(一个订阅覆盖
模型 + 联网搜索 + 图像 + 语音):

```bash
hermes setup --portal
```

### 4. 启动大脑 + 保活

```bash
bash scripts/android/hermes-termux-run.sh
```

这个脚本会:
- 拿**唤醒锁**阻止手机休眠;
- 检测到你的 **root** 后,把 Termux 加入省电(Doze)白名单,尽量不被杀;
- 后端万一崩了自动重启。

保持这个 Termux 窗口开着(可以切到后台)。想停就回到窗口按 `Ctrl+C`。

### 5. 打开"脸",并变成主屏幕上的 App

- 用手机 **Chrome** 打开: **http://127.0.0.1:9119**
- 右上角菜单 →【**添加到主屏幕**】或【**安装应用**】
- 桌面上就会出现一个 **Hermes 图标**,点开是独立窗口,和真 App 几乎一样 🎉

> 这一步用到的技术叫 **PWA**。我们已经给界面加好了(应用图标、独立窗口、
> 离线时的基本骨架),所以"添加到主屏幕"才会变成一个像样的 App。

### 6. 让它读你的手机文件

在对话框里直接用大白话说,例如:

- 「列一下 `/sdcard/Download` 里有哪些文件」
- 「读一下 `/sdcard/Documents/xxx.txt` 的内容并总结」
- 「把 `/sdcard/DCIM/Camera` 最新的照片描述一下」

需要读**受限位置**(别的 App 的私有数据等)?因为你有 root,可以在对话里让它
用 `su` 提权读取,例如:

- 「用 `su -c 'ls /data/data'` 看看装了哪些 App 的数据目录」

> ⚠️ 安全提醒:root + 能读全盘是很强的能力。只在你信任的模型/配置下使用,
> 不要把这个后端暴露到公网(默认只绑定 `127.0.0.1` 本机,是安全的)。

## 四、关于"后台被杀"(重要的实话)

安卓为了省电,会主动杀掉后台进程。Termux 里的大脑也不例外。我们用**唤醒锁 +
root Doze 白名单 + 自动重启**尽量缓解,但**没法 100% 保证**它永远不被杀 ——
这是安卓系统的限制,不是 Bug。

进一步提升存活率(手机系统设置里做一次):
- 给 **Termux** 关闭电池优化 / 设为"无限制"后台;
- 允许 Termux **自启动**(部分国产 ROM 有这个开关);
- 在"最近任务"里给 Termux **加锁**,别手滑清掉。

> 如果你希望它 **7×24 永远在线**,最稳的办法是让"大脑"跑在一台常开的电脑/
> 服务器上(见第五步),手机只当"脸"。你电脑快到了,到时切过去就行。

## 五、第二步:电脑到了以后(可选升级)

### 方式 A(推荐):手机连"电脑上的大脑"

好处:更稳、不占手机、后台不会被杀。

1. 在电脑上装好 Hermes(仓库根目录 `README.md` 的安装方式),然后让大脑监听
   局域网:
   ```bash
   hermes dashboard --host 0.0.0.0 --port 9119
   ```
   > 公网绑定会强制要求登录鉴权(OAuth),这是安全设计。**最省心的做法是让
   > 手机和电脑处于同一 WiFi,或用 [Tailscale](https://tailscale.com) 组一个
   > 私有网络**,这样可以用简单的 token 直连,不用折腾公网。

2. 手机端两种连法:
   - **PWA / 浏览器**:如果电脑端开了跨域许可,手机浏览器直接开电脑的地址;
     或在 App 设置里填入"网关地址 + token"(见下方《连接覆盖》)。
   - **正式 APK**:见方式 B,把 `server.url` 改成电脑地址即可。

3. 跨域许可(仅当手机页面和大脑不同源时需要):在电脑启动大脑前设置
   ```bash
   export HERMES_DASHBOARD_EXTRA_CORS_ORIGINS="http://localhost,https://你的手机App来源"
   ```
   (默认空 = 只允许本机,最安全。)

#### 连接覆盖(把手机 App 指向任意大脑)

我们内置了一个开关,让"脸"可以连到任意"大脑"(本机或远程),用于打包 App 或
以后连电脑。它**默认不生效**,不设置时行为和现在完全一样。设置方式:

- 由原生外壳注入:`window.__HERMES_GATEWAY_ORIGIN__`(如 `http://127.0.0.1:9119`)
  和 `window.__HERMES_GATEWAY_TOKEN__`(大脑启动时打印的会话 token);
- 或在浏览器控制台/未来的设置页里调用 `setGatewayConfig({ origin, token })`。

实现见 [`web/src/lib/gateway-origin.ts`](../../web/src/lib/gateway-origin.ts)。

### 方式 B:打包成正式 .apk 安装包

用 Capacitor 把界面打包成原生安卓 App。完整步骤见
[`apps/android/README.md`](../../apps/android/README.md)。概览:

```bash
npm install                                   # 仓库根目录
npm --workspace web run build                 # 先构建界面
npm --workspace @hermes/android install
npm --workspace @hermes/android run add:android
npm --workspace @hermes/android run sync
npm --workspace @hermes/android run open      # 在 Android Studio 里点 ▶ 出 APK
```

默认 `server.url = http://127.0.0.1:9119`(连手机本机 Termux 大脑);连电脑就
把它改成电脑的 `https://...` 地址。

## 六、手动安装(第一步的备选方案)

如果一键脚本失败,可以手动来:

```bash
pkg update && pkg install -y python git rust binutils clang make ripgrep openssl libjpeg-turbo termux-api
termux-setup-storage        # 手机弹窗点“允许”
git clone https://github.com/NousResearch/hermes-agent && cd hermes-agent
python -m venv venv && . venv/bin/activate
export ANDROID_API_LEVEL="$(getprop ro.build.version.sdk)"
pip install -e '.[termux]' -c constraints-termux.txt
hermes setup
hermes dashboard --host 127.0.0.1 --port 9119 --no-open
```

## 七、常见问题(FAQ)

**Q:浏览器打开 127.0.0.1:9119 打不开?**
A:确认那个 `hermes-termux-run.sh` 窗口还开着、没报错;端口被占就换端口:
`bash scripts/android/hermes-termux-run.sh --port 9200`,浏览器也用新端口。

**Q:锁屏一会儿就断线 / 后端没了?**
A:被安卓杀了。按第四节做电池/自启设置;彻底稳定就走第五步(连电脑)。

**Q:它说读不到某个文件?**
A:先确认路径对(`/sdcard/...`);受限位置让它用 `su -c` 读(你有 root)。
存储权限没给的话,重跑 `termux-setup-storage`。

**Q:一定要有 root 吗?**
A:不是必须。没有 root 也能用第一步,只是①后台更容易被杀 ②只能读 `/sdcard`
这类共享目录。你有 root,这两点都能改善。

**Q:能不能不用电脑就打出 .apk?**
A:很难,不建议。打包 APK 需要安卓开发工具链(Android SDK)。在没有电脑时,
**PWA(第一步的"添加到主屏幕")就是你的 App**,体验已经很接近了。

## 八、这次为支持安卓改了什么(给懂技术的你)

- **PWA**:`web/public/manifest.webmanifest`、`web/public/hermes-sw.js`(保守型
  Service Worker,只缓存带哈希的静态资源,绝不缓存 `/api/` 与会话 token)、
  `web/index.html` 注册 SW 与移动端 meta;`hermes_cli/web_server.py` 补上
  manifest/icons 的子路径反代重写。
- **连接覆盖层**:`web/src/lib/gateway-origin.ts`(默认不生效),接入
  `web/src/lib/api.ts` 与 `web/src/lib/gatewayClient.ts`,让"脸"可指向任意
  "大脑"(本机/远程),为打包 APK 和"以后连电脑"预留接口;含单元测试
  `web/src/lib/gateway-origin.test.ts`。
- **跨域开关**:`HERMES_DASHBOARD_EXTRA_CORS_ORIGINS` 环境变量(默认空,行为
  不变),供远程/跨域场景显式放行来源。
- **Termux 脚本**:`scripts/android/hermes-termux-setup.sh`(一键安装)、
  `hermes-termux-run.sh`(启动 + 唤醒锁 + root Doze 白名单 + 看门狗)。
- **Capacitor 脚手架**:`apps/android/`(打正式 APK 用)。

> 说明:本仓库的自动化环境无法连真机 / 无安卓 SDK,以上代码与脚本按官方已支持
> 的 Termux 路径与既有 Web 架构编写,APK 构建与真机运行需在你的手机/电脑上完成。
